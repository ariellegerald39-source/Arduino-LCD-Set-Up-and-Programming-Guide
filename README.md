Arduino LCD 16x2 Project

A Tinkercad simulation demonstrating an Arduino Uno controlling a 16x2 LCD display in 4-bit parallel mode.

Features Demonstrated

Print Text: Displays static character strings.

Position Text: Uses coordinate mapping (setCursor) to target specific rows and columns.

Scroll Text: Shifts text across the screen (scrollDisplayLeft).

Custom Characters: Renders a user-defined pixel-mapped heart icon (createChar).

Blink Text: Toggles cursor blinking effects.
